# Frame Splitter

画像を **原寸のまま**、余白が最小になるように1枚へまとめるツールです。
`index.html` をブラウザで開くだけで動きます。インストールもビルドも要りません。

処理はすべてブラウザの中で終わります。画像はどこにも送信されません。
サーバーも API キーも不要なので、料金は一切かかりません。

---

## 使い方

画像をドロップすると、その場でまとまった1枚ができます。設定項目はありません。

- **画質は落ちません。** 拡大も縮小もせず、原寸のまま並べます。
  1920×1080 が4枚なら、そのまま4枚分の面積になります。
- 保存形式は PNG です。PNG は圧縮しても画素が変わらないため、元画像の見た目がそのまま残ります。
- 余った部分は透明のままにします。白地を作りません。
- Ctrl+V の貼り付けでも追加できます。
- 結果が気に入らないときは「別の並びにする」で次の候補へ切り替えられます。

---

## 並べ方の決め方

キャンバスの幅の候補（画像の幅の組み合わせ和すべて）を総当たりし、それぞれで詰め込みを試します。
詰め込みは MaxRects という手法で、回転はしません。各案を次の式で採点し、良い順に最大6案を残します。

```
点数 ＝ 充填率 − 縦横比のずれ × ASPECT_WEIGHT
```

縦横比のずれを見るのは、余白ゼロだけを追うと 8672×1080 のような細長い帯が選ばれてしまうためです。
また、画面が横長なので **横長寄り（比 1.3）を目標**にしています。目標を 1.0（正方形）にすると、
縦積みの方が正方形に近いという理由で縦長ばかり選ばれます。

好みに合わないときは `index.html` の先頭にある2行を書き換えます。

```js
const ASPECT_TARGET = 1.3;   // 1 より大きいほど横長寄りを選ぶ
const ASPECT_WEIGHT = 0.30;  // 上げるほど形を優先、下げるほど余白ゼロを優先
```

実測した候補の並びです。左が既定で、「別の並びにする」を押すと右へ移ります。

```
1920×1080 を 2枚        1920×2160(0%)   3840×1080(0%)
1920×1080 を 3枚        1920×3240(0%)   3840×2160(25%)  5760×1080(0%)
1920×1080 を 4枚        3840×2160(0%)   1920×4320(0%)   7680×1080(0%)
1456×1080 を 3枚        2912×2160(25%)  1456×3240(0%)   4368×1080(0%)
16:9 を2枚 + 三面図1枚    3376×2160(22%)  1920×3240(8%)   5296×1080(0%)
16:9 を3枚 + 三面図1枚    3840×2160(6%)   3376×3240(29%)  1920×4320(6%)
```

サイズが混ざると、原寸を守る以上どこかに隙間が出ます。

## 共有

`index.html` を GitHub Pages に置けば、URL を渡すだけで誰でも使えます。
サーバー処理も認証もないので、渡した相手に入力してもらうものはありません。
