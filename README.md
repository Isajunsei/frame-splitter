# Frame Splitter

画像を **原寸のまま**、余白なしで1枚へまとめるツールです。
`index.html` をブラウザで開くだけで動きます。インストールもビルドも要りません。

処理はすべてブラウザの中で終わります。画像はどこにも送信されません。
サーバーも API キーも不要なので、料金は一切かかりません。

公開URL: https://isajunsei.github.io/frame-splitter/

---

## 使い方

画像をドロップすると、その場でまとまった1枚ができます。設定項目はありません。

- **余白は出ません。** 幅をそろえて段に組むので、隙間はゼロになります。
- **初期合成では縮小しません。** 段の高さは、その段で一番大きい元画像に合わせます。
  どの画像も元のサイズ以上になるので、元の画素を捨てません。
  幅の違う画像が混ざったときは、**小さい方を拡大して**幅をそろえます。
- 保存形式は PNG です。PNG は圧縮しても画素が変わらないため、見た目がそのまま残ります。
- Ctrl+V の貼り付けでも追加できます。
- 結果カードの白い余白をクリックすると、画像を全部消して初期状態に戻ります。

## 2種類の「並び替え」（別物）

### A. 「別の並びにする」ボタン

- **全体レイアウト（段の分け方）を別候補に切り替える**
- 完成画像の **縦横比・全体サイズが変わりうる**（縦長／横長になり得る）
- 最大6候補。採点順（正方形寄り・拡大少なめ優先）
- 押すと、下のドラッグ入れ替え状態はリセットされる

### B. 完成画像をドラッグ＆ドロップ（枠の入れ替え）

- **いま表示中の縦横比・枠の形・全体サイズは絶対に変えない**
- 枠（スロット）の位置と大きさは固定したまま、**枠どうしの中身だけを入れ替える**
- 操作: 入れ替えたい枠をドラッグし、相手の枠の上でドロップ
  - 例: 右下を掴んで左上へドロップ → 右下と左上が入れ替わる
- 3枚でも4枚でも5枚でも同じ。任意の2枠を直接入れ替えられる
- 入れ替え後の各枠の描画は **cover（余白なし）**:
  - 枠を必ず全面で埋める（市松の空きを出さない）
  - アスペクト比は維持
  - 足りない辺に合わせて拡大／縮小し、はみ出す辺は **中央基準で外側からカット**
- 画像の追加・削除・全部消す・「別の並びにする」でも入れ替え状態はリセット

## 並べ方の決め方（初期合成 / 候補A）

画像を何段かに分け、同じ段の画像は高さをそろえ、各段の合計幅をキャンバス幅にぴったり合わせます。
この作り方なら余白は必ずゼロになります。段の分け方をすべて試し、次の式で採点します。

```
点数 ＝ −（正方形からの遠さ × ASPECT_WEIGHT）−（拡大の大きさ × UPSCALE_WEIGHT）
```

**正方形に近いものから順に出ます。** そのままだと 1699×378 のような細長い帯が候補になりますが、
使いにくいので後ろに回ります。拡大の大きさも見るのは、形を整えようとして
小さい画像を何倍にも引き伸ばすのを防ぐためです。

好みに合わないときは `index.html` の先頭にある定数を書き換えます。

```js
const ASPECT_TARGET  = 1.15;  // 1 が正方形。少しだけ横長寄りにしている
const ASPECT_WEIGHT  = 1.00;  // 上げるほど正方形寄りを先に出す
const UPSCALE_WEIGHT = 1.5;   // 上げるほど元のサイズを保とうとする
const MAX_CANDIDATES = 6;     // 「別の並びにする」で回せる候補の数
```

実測した候補です。左が既定で、「別の並びにする」を押すと右へ移ります。
括弧内は、その案でいちばん大きい拡大率です。

```
778×378 + 397×163       778×697(1.96倍)     1699×378(2.32倍)
1920×1080 を 2枚         1920×2160(等倍)     3840×1080(等倍)
1920×1080 を 3枚         3840×3240(2.00倍)   1920×3240(等倍)     5760×1080(等倍)
1920×1080 を 4枚         3840×2160(等倍)     5760×4320(3.00倍)   1920×4320(等倍)
1456×1080 を 3枚         2912×3240(2.00倍)   1456×3240(等倍)     4368×1080(等倍)
16:9 を2枚 + 三面図1枚     3376×2979(1.76倍)   3840×3928(2.64倍)   1920×3584(1.32倍)
16:9 を3枚 + 三面図1枚     3840×2308(1.14倍)   5296×4059(2.76倍)   5760×5353(3.96倍)
```

## ファビコンを変える

`icons` フォルダに3案が入っています。いま使っているのは候補B（青地）です。

```
icons/favicon.svg              いま使っているもの
icons/favicon-候補A-白地.svg    白い角丸に青系のブロック
icons/favicon-候補B-青地.svg    濃い青に白いブロック。小さくしても見分けが付きます
icons/favicon-候補C-3色.svg     青・橙・緑・紺の4ブロック
icons/見比べ.png                3案を並べたシート
```

気分で変えるときは、使いたい候補を **`favicon.svg` という名前で上書きコピー**します。
`index.html` は `icons/favicon.svg` を読むだけなので、他に直すところはありません。
